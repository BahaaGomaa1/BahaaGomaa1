## 📌 Featured Projects

### 🚚 AI WhatsApp Dispatch Agent

An AI-powered WhatsApp dispatch system built with **n8n, Evolution API, OpenRouter and PostgreSQL**.

Designed to manage customer requests for:

📦 **Parcels**
🏍️ **Passengers**
🍔 **Food Delivery**

The agent collects the required information, identifies the request type, routes the order to the relevant captain group, and supports dispatch decisions using location and distance logic.

**Tech Stack**

`n8n` `AI Agents` `OpenRouter` `Evolution API` `WhatsApp` `PostgreSQL` `Docker`

---

### 💰 AI Price Comparison Agent

An AI Agent built with **Python + LangChain** for comparing product prices using web search and returning structured results.

The project combines AI reasoning with external tools to provide useful price comparison results.

**Tech Stack**

`Python` `LangChain` `AI Agents` `Web Search` `Telegram` `Email`
